    How to build the map
    1. Pick a map. Tap Generate map, or type a code into Load a code. Share the map code so others can follow along on their own phones.
    2. Sort the tiles. Make one pile for each pair of terrains, such as Plains / Mountains. Tiles in the same pile are interchangeable.
    3. Start Build mode. Tap Build this map at the table. If the map uses fewer than 80 tiles, pull the tiles it lists from each pile.
    4. Line up your phone with the table. Tiles point up and icons sit upright, the same as on screen.
    5. Place the center tile in the middle of your play area.
    6. Follow each step. Take the numbered tile from the pile it names, turn the named side up, and place it where the step says: next to the last tile, or next to the tile outlined on the map. The map grows outward ring by ring, clockwise.
    7. Add the pieces. When every tile is down, put your meeple on the tile with the orange border (the start) and the end token on the tile with the black border.
